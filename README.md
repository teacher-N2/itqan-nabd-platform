# إتقان | نبض — V6.1

نسخة موسّعة من بنك نبض للصف الخامس — الفصل الدراسي الأول.

- 420 سؤالًا ومهمة.
- خمسة أغراض تربوية لكل مهارة دقيقة: تثبيت، تدريب موازٍ، أداء مستقل، إعادة قياس، إثراء.
- تصفية حسب الوحدة والدرس والمهارة.
- اختيار عشوائي من النتائج الحالية مع تقليل تكرار السؤال محليًا.
- أسئلة موضوعية، وإجابات قصيرة، ومهام كتابية، ومهام ملاحظة/استماع/تحدث.
- ملف الإجابات الذي زودت به المعلمة جزئي؛ لذلك لا تُنسب الإجابات المنشأة للمنصة إلى مفتاح رسمي كامل.

هذه النسخة ما زالت محلية التخزين؛ المزامنة بين الأجهزة ستأتي في مرحلة قاعدة البيانات.
