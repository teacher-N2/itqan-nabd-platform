المرحلة الرابعة: نبض أسبوعي متغير + بنية Supabase حقيقية.

- جدول أسبوعي من الأحد إلى الخميس للطالبة.
- اختيار الوحدة والدرس من لوحة المعلمة وتوليد خمسة نبضات من بنك الـ420.
- نشر/إلغاء نشر الأسبوع في الوضع التجريبي.
- ملف `supabase-v7.js` يحتوي فقط على رابط المشروع والمفتاح القابل للنشر (Publishable Key)، وليس أي مفتاح سري.
- قاعدة البيانات في Supabase تحتوي مخطط الوحدات والدروس وبنك الأسئلة والأسابيع والعناصر والمحاولات مع RLS.
- إنشاء حسابات المعلمة والطالبات وتعبئة البيانات النهائية خطوة التهيئة التالية داخل V7.
