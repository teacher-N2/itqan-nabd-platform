# إتقان | نبض — المرحلة الثالثة V6

نسخة تجريبية مستقلة لمنصة رفع التحصيل في اللغة العربية للصف الخامس — الفصل الدراسي الأول 2026–2027.

## الجديد في V6
- دورة نشر كاملة: إنشاء السؤال → تحديد المستهدفات → مكان الظهور → التاريخ → النقاط → النشر.
- تظهر المهمة المنشورة للطالبة المستهدفة في «نبض اليوم» على الجهاز نفسه في هذه النسخة المحلية.
- دعم اختيار من متعدد، وإجابة قصيرة، وأداء كتابي، وملاحظة المعلمة.
- بنك نبض أولي: 84 سؤالًا/مهمة، عنصر واحد لكل مهارة دقيقة في خريطة المنهج الحالية.
- كل عنصر في البنك مربوط بالوحدة والدرس والصفحة والمهارة والمهارة الدقيقة.
- الأسئلة أصلية موازية للمنهج وليست نسخًا حرفيًا من تدريبات الكتاب.

## مهم
الحفظ في هذه النسخة يتم في localStorage على الجهاز فقط. ربط Supabase في المرحلة التالية سيحوّل النشر والنتائج إلى قاعدة بيانات مشتركة بين أجهزة الطالبات ولوحة المعلمة.
